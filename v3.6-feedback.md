## UX direction (locked 2026-05-21): Option B

No web wrapper, no terminal-only. The terminal is **transport**, not interface. Every user-facing string in `SKILL.md` gets rewritten to read like a human strategist talking — no `.md` suffixes, no file paths, no slash commands surfaced, no "open Claude Code in this folder" instructions.

**Before:** "Wrote `profile/strategy.md`. Run `/strategist mine` when you have new transcripts."
**After:** "I've locked your strategy. When you drop a new transcript in, I'll pick it up next time we talk — you don't need to do anything."

Apply this rewrite-rule across:
- Phase 1 synthesis "Locked" message
- Phase 2 sub-track configuration
- Phase 2 close message
- Phase 3 no-arg behavior
- All verb responses (grill, generate, voice, mine, capture, trends)
- ONBOARDING.md
- README.md (keep technical-shaped, since this is the install doc)

Test: read every output line aloud — would Karen Kelly understand it without asking "what's a .md file?" If no, rewrite.


# v3.6 Feedback — From Bella's Real Walkthrough

Collected 2026-05-21 while she stress-tested the strategist by walking the flow as both builder and user.

## Wording fixes (small, mechanical)

### Q3 — "Dinner party for your ideal audience"
**Bella:** "this one is confusing"
**Fix:** Simplify framing. The "imagine X at a dinner party" frame is a writing-class cliché that lands as a non-sequitur after Q1/Q2 already established who she is.

### Q5 — "What's off-limits"
**Bella:** "we should explain this more like... now that we know what you wanna talk about and get inspired from, what's something you absolutely will never want to talk about in your content"
**Fix:** Reframe as a **contrast** to the topics surfaced in Q1/Q2. The current version drops a generic 11-item checklist of categories (kids/health/finances/etc) without referencing what they just said they DO want to talk about. Should pull from prior answers.

### Q6 — "What is your content FOR?"
**Bella:** "this is redundant from the beginning"
**Fix:** Kill or merge into Q2 (the why-now + 12-month picture already asks this). Currently asking the same money-path question twice with different framing.

## Architectural — adaptive specificity

**Bella:** "as they go through the prompt i want it to get customized and ask more specific questions depending what they say... like it gets more specific the more it learns the area/person/etc"

The intake is currently a fixed script: same 6 bio questions for everyone. The fix is **branching specificity**: each answer should narrow what the next question even looks like. If Q1 says "VC analyst," Q2 shouldn't be generic — it should already ask about founder-facing vs LP-facing audiences. If Q1 says "children's book author," Q2 shouldn't reference founders at all.

This is the biggest single-shot change to intake quality.

## Voice extraction — pull, don't push

### Step 3 (Speaking sample)
**Bella:** "this should tell them claude can listen to a transcript if they go to apify... or can claude go onto tiktok or reels to see"
**Fix:** Don't require pasting transcripts. If they have public socials (TikTok handle, IG, Reels), the strategist should **auto-pull captions/transcripts via Apify** (or scrape directly). Asking creators to manually paste their own content back is friction nobody clears.

### Step 4 (Voice north stars)
**Bella:** "this should be what content creators have you seen that you like and resonate with that you think your content to be similar, like competitors almost... and can claude point and read those accounts?"
**Fix:** Reframe as "creators you want to sound similar to / compete with" (more intuitive than "voice north stars"). Then **auto-fetch and read those accounts** — pull their last N posts, analyze structure, store as voice priors. Currently the names are inert strings.

## Garden framing — surface one piece at a time

**Bella:** "i think the garden framing for them is weird like perhaps we give them 1 content piece and offer like hey if this doesn't resonate we can delete this from the idea log or we can move to the next idea and park it or something like that"

Phase 3 currently surfaces aggregate state: "garden's at 6 post-worthy seeds, none developed in 8 days, 0 teardowns in 14 days." That's a status report, not a creative prompt. **Better:** pull ONE specific seed and offer:
- ✅ Develop this → goes to grill/draft flow
- 🗑 Delete → trash, learn the classifier wasn't right
- ⏸ Park → skip to next, no judgment

Tinder-style swipe through ideas, one at a time. Much lower cognitive load than "here's your garden's vital signs."

## Trend watcher — news is missing

**Bella:** "this should also include news most importantly, like find news articles publicly"

Currently lists Reddit/RSS/HN/PH. **News should be primary**, not absent. News articles are the most timely teardown material — and the most relevant for someone like Bella whose pillar 2 IS teardown. Add a news source (Google News RSS, NewsAPI, or curated outlet RSS list).

## 🚨 The big one — UX gap for non-technical users

**Bella:** "this looks like too much for the user to understand and not know how to access the strategist... ugh wtf most people aren't in their terminal"

The synthesis screen drops file paths (`profile/strategy.md`, `~/Desktop/Vault/_team/brand-manager/`), references slash commands (`/strategist`, `/strategist mine`), and expects the user to understand "open Claude Code in this folder." None of those concepts exist for Karen Kelly, Morris, or the children's book author.

This isn't a wording problem. It's a **distribution problem**. Three possible answers:

| Option | What it means |
|---|---|
| **A. Hide the terminal entirely** | Build a thin web/desktop wrapper around the skill. Users never see file paths or slash commands. Big lift. |
| **B. Translate terminal-speak to plain English in the skill output** | The skill itself stops mentioning file paths. Says "I saved your strategy" not "Wrote profile/strategy.md." Still terminal-distributed, but the UX inside the terminal is human. Medium lift. |
| **C. Ship to terminal-comfortable users only** | Bella, technical creators, anyone already in Claude Code. Skip Karen/Morris as targets. Small lift but small market. |

Bella's "wtf most people aren't in their terminal" suggests A or B. B is the cheaper proof — if the terminal output reads like a human strategist talking, the terminal becomes invisible to the user. They just paste in stuff and read responses. The terminal is a transport, not the product.
